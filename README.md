# Matematică — pregătire admitere UTCN

Culegerea: [`teste-grila-utcn.pdf`](teste-grila-utcn.pdf) (416 probleme: cele din culegerea oficială 2026 + câte 3 asemănătoare pentru fiecare, cu rezolvări și tabel de răspunsuri).

## Cum lucrăm

1. Rezolvi pe caiet, cu **condițiile de existență scrise înainte de calcul** și cu calculul dus până la rezultat, fără variantele în față.
2. Fotografiezi paginile și le pui în folderul temei, `<capitol>/tema-AAAA-LL-ZZ/`, cu numerele problemelor în numele pozei (ex. `26-30-40.jpeg`).
3. `git add` + `git commit` + `git push`.
4. Verificarea vine în `review/` (PDF), iar tabelul din README-ul capitolului se actualizează.
